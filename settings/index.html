BLE mesh network

This network's keys live only in this app's settings — there is no export or import. If these settings are lost — removing or reinstalling this app, or resetting Homey itself — every bulb stays bound to a network nobody can reach anymore. The only way back is a physical factory reset of each bulb, followed by pairing it again. A Homey backup (which includes this app's settings) protects against this; this app offers no separate backup of its own.
